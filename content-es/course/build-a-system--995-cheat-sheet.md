Un recordatorio de una página de este módulo. Lee primero las lecciones; usa esto para refrescar la memoria.

## Lo esencial

- **Un sistema** son reglas escritas de mercado, estilo, entrada, stop, tamaño, salida y revisión.
- **Estilo:** elige uno que encaje con tu tiempo, tus costes y tus nervios (scalping, day, swing, inversión).
- **Entrada:** contexto, disparador, tipo de orden, stop. Sin setup no hay operación.
- **Salidas:** planifica ambas antes de entrar: stop (error) y regla de beneficio (acierto). Nunca amplíes un stop.
- **Gestionar una operación:** comprueba que el stop está puesto, sigue el plan, no metas mano.
- **Lista** antes de cada operación; **diario** después de cada una; **revisión semanal** para las infracciones.
- **Prueba primero:** backtest con reglas exactas y costes, luego papel, luego operaciones diminutas.
- **Cambia las reglas** rara vez: suficientes operaciones, un cambio cada vez.

## Un plan de una página tiene

Mercado y estilo · contexto · entrada · stop · tamaño (alrededor del 1 % de riesgo) · salidas · límites de pérdida · lista · ritmo de revisión

## Ojo con

- Copiar el sistema de otra persona sin cambios.
- Retocar hasta que el backtest se vea bien.
- Saltarte el diario.

**Contenido educativo, no asesoramiento financiero.**
